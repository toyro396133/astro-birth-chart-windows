# Astro Birth Chart Windows — גרסה 0.2

תוכנת Windows מקומית לחישוב מפת לידה אסטרונומית: ממשק עברי RTL, מיקומי עשרה גופים, נסיגה, אופק/MC, בתי Whole Sign, היבטים וגלגל מפה. אין שרת, חשבונות, אנליטיקה או העברת נתוני לידה.

## התחלה על Windows

דרושות Python 3.12 ו-Python Launcher (py).

1. הורידו את המאגר.
2. פתחו PowerShell בשורש המאגר.
3. הריצו:  .\scripts\build_windows.ps1
4. פתחו:  dist\AstroBirthChart\AstroBirthChart.exe

הסקריפט מוריד את האפמריס *בזמן הבנייה בלבד*, בודק את חתימתו, מריץ בדיקות ומייצר EXE ותיקיית קבצי ריצה נלווים. יש להעתיק את **כל** התיקייה dist/AstroBirthChart, ולא רק את קובץ ה-EXE. אחרי הבנייה אין צורך בחיבור לאינטרנט.

## תחומי דיוק

- גלגל טרופי; אורכי הגופים הם גאוצנטריים, apparent, במסגרת true ecliptic/equinox of date באמצעות Skyfield ו-JPL DE440s.
- מאדים, צדק, שבתאי, אורנוס, נפטון ופלוטו ממוקמים לפי מרכזי מסה (barycenters) שמספקת DE440s; קיים הבדל זעיר לעומת מרכזי הדיסקה.
- טווח התוכנה: 1850–2149, בהתאם לאפמריס; שעת לידה מלאה מאפשרת חישוב בתים ו-MC/Asc.
- אזורי זמן היסטוריים מתקבלים מ-IANA דרך tzdata מקומי; שעה כפולה/לא קיימת במעבר שעון מוחזרת כשגיאה, לא מנחשים.
- בשעה לא ידועה אין אופק/MC/בתים. המעלות וההיבטים המסומנים 'דגימה' אינם תוצאה מדויקת; אם גוף עשוי להחליף מזל, מוצגות האפשרויות.
- פרטי חישוב אינם נשמרים ואינם נשלחים כלל; שכבת אחסון תתווסף רק אם תהיה דרישה מפורשת.

## הזנת תאריך עברי וזמן משוער

במסך **סוג תאריך** בחרו **עברי**. בחרו שנה, חודש ויום עבריים. רשימת
החודשים מתעדכנת אוטומטית לפי שנה פשוטה/מעוברת, ותאריכים שאינם קיימים
אינם מתקבלים. המרה מבוצעת במחשב באמצעות pyluach 2.3.0 (רישיון MIT),
ללא שירות רשת וללא שמירת הנתונים.

יש לבחור גם **יום**, **לילה — לפני חצות**, או **לילה — אחרי חצות**:
- יום: התאריך הלועזי של היום המתאים לתאריך העברי.
- לילה לפני חצות: הערב שלפני התאריך הלועזי הזה, ולכן *יום לועזי קודם*.
- לילה אחרי חצות: אותו תאריך לועזי של היום, בשעות שלפני הזריחה.

שעת ברירת המחדל היא 12:00 ביום, 21:00 בערב ו־01:00 אחרי חצות. אלו
**הצעות בלבד ולא שעת לידה ידועה**: אפשר לשנות את השעה, וסימון
**שעה בקירוב** יישאר דולק עד שהמשתמש יבטל אותו. אופק/MC/בתים מחושבים
לשעה המשוערת ומסומנים כאומדן — אין להציגם כנתון ודאי.

למניעת טעויות תאריך, עם חישוב המפה נבדק גובה השמש מעל האופק לפי האפמריס
והקואורדינטות המקומיות. בחירת יום בזמן לילה מובהק או בחירת לילה בזמן
יום מובהק נדחות. סמוך לשקיעה או זריחה מוצגת אזהרה על אי־ודאות.
זו בדיקה אסטרונומית בקירוב (ללא אופק טופוגרפי), לא קביעה של זמן שקיעה
מקומי מדויק. במקרה שאין שעה כלל, ניתן להשתמש במצב התאריך הלועזי עם
"שעת הלידה אינה ידועה"; המערכת אינה ממציאה שעה כדי לקבוע בתים.

הספרייה pyluach היא MIT: https://pypi.org/project/pyluach/


## גרסאות ועדכונים (מ־v0.2.0)

המחשב ממשיך לפעול ללא אינטרנט כשהעדכונים כבויים (ברירת המחדל).
בכותרת הממשק יש מספר גרסה, **בדוק עדכונים**, ו־**עדכונים אוטומטיים**.
כאשר מפעילים עדכונים אוטומטיים, היישום בודק בפתיחתו רק את דף
GitHub Releases של המאגר הזה. עדכון חדש יורד ברקע, נבדק ומוכן להתקנה;
לאחר מכן המשתמש מתבקש לאשר הפעלה מחדש. אף נתון לידה אינו משודר.

האימות מחייב:
- קובץ מתוך GitHub Releases היציבים של המאגר המוגדר בקוד בלבד.
- שם חבילה קבוע `AstroBirthChart-Windows-x64.zip`, תג `vX.Y.Z`, גרסה חדשה יותר.
- גודל קובץ וחותמת SHA-256 שפורסמו ב־GitHub Releases API; בהיעדר חתימה
  תקינה העדכון נחסם, ולא נופלים ל־HTTP.
- בדיקות נגד ZIP Slip, קישורים סמליים, גדלים חריגים וקבצים כפולים;
  בדיקת `version.json` ומרכיבי החבילה לפני התקנה.

רכיב `AstroBirthChartUpdater.exe` עצמאי ומועתק לתיקייה זמנית מחוץ לתוכנה.
לאחר סגירת היישום, הוא מחליף את תיקיית ההתקנה ומשאיר עותק גיבוי
בצד, בשם `.astrochart-backup-*`. אם ההחלפה או הפעלה מחדש נכשלים מיד,
רכיב העדכון משחזר את התיקייה הישנה. אין לשמור נתוני משתמש בתיקיית
היישום עצמה.

**מגבלה חשובה:** אימות ה־SHA-256 עוקב אחר מה ש־GitHub מפרסם;
זה אינו חתימה קריפטוגרפית עצמאית של המפתח. לפני הפצה רחבה רצוי להוסיף
חתימת קוד/עדכונים שאינה תלויה בחשבון GitHub, ולאמת תנאי רישוי צד שלישי.
פרטי התהליך: [docs/updates.md](docs/updates.md).

גרסאות יציבות נבנות באמצעות workflow נפרד בהעלאת תג סמנטי המצביע על
ה־commit האחרון ב־main. אין הפצת עדכון רק מעצם מיזוג קוד או העברת

## התקנה רגילה ב־Windows (Setup.exe)

בנוסף לגרסת Portable, המערכת בונה כעת **קובץ התקנה יחיד**
`AstroBirthChart-Setup.exe` באמצעות Inno Setup:

- לחיצה כפולה פותחת אשף התקנה ומתקינה את כל הקבצים אוטומטית.
- ההתקנה היא **למשתמש הנוכחי**, בברירת מחדל תחת
  `%LOCALAPPDATA%\Programs\AstroBirthChart`; אין צורך בהרשאות מנהל.
- נוצר קיצור דרך בתפריט ההתחלה; קיצור דרך בשולחן העבודה לבחירה.
- התוכנה מופיעה ב־Windows **הגדרות > יישומים > יישומים מותקנים**;
  אפשר להסיר אותה מכאן בלי למחוק קבצים ידנית.
- התקנת גרסה חדשה משתמשת באותו `AppId`, מעדכנת את הקבצים ומשמרת את
  מערכת הרישום וההסרה של Windows.
- הבדיקה האוטומטית מזהה התקנת Setup, מורידה ואומדת חותמת של
  `AstroBirthChart-Setup.exe` החדש ומפעילה את Inno Setup כעדכון לאחר
  סגירת התוכנה. **אין החלפת תיקייה ידנית** בהתקנות רשומות.
- גרסת Portable נשארת זמינה בנפרד כ־ZIP, עם מנגנון העדכון הישן.
  **אי אפשר להפוך ZIP ישן למתקין רשום באמצעות לחיצה על בדוק עדכונים**:
  התקנת Setup.exe נדרשת פעם אחת למעבר למצב מותקן.

שימו לב: המתקין לא חתום ב־Authenticode בשלב זה; Windows SmartScreen
עשוי להציג אזהרת מפרסם לא ידוע. זה אינו אישור לעקוף אזהרות
שרשרת אספקה: יש להוריד קבצים רק מערוץ GitHub הרשמי.


## עיצוב הממשק — גרסה 0.3.0

עיצוב מחודש של ממשק PySide6 המקורי, בעברית וכיווניות ימין־לשמאל:

- כותרת אפליקציה מובחנת, תווית גרסה, אפשרות עדכונים וכפתור בדיקה.
- כרטיס הזנת לידה עם תאריך עברי/לועזי, שעה בקירוב ובחירת מקום.
- קווי רוחב/אורך ואזור זמן נמצאים כעת ב־"הגדרות מיקום מתקדמות";
  בחירה ב"הזנה ידנית" פותחת את ההגדרות אוטומטית.
- כרטיסי תוצאות נפרדים לגלגל המפה ולטבלה; היבטים והערות במיקום עקבי.
- גלגל מפה וקטורי עם טבעות מעודנות, צבעי סמלים ומבנה נגיש יותר.
- הערות ארוכות נגללות בפני עצמן במקום לדחוק את הטבלה מחוץ למסך.
- בדיקות GUI ב־1024×790 וב־1360×860 עם צילומי מסך אמיתיים.

העיצוב אינו דורש חיבור לאינטרנט, קובצי תמונה או גופנים להורדה;
כל הרכיבים נטענים מקומית, והחישובים נשארו ללא שינוי. קוד העיצוב
מופרד ל־`src/astrochart/theme.py`, כך שאפשר לעדכן את המראה
בלי להתערב במנוע האסטרונומי.


## מנוע פרשנות אופי אסטרולוגית — גרסת ניסוי

נוסף מנוע **כללים עריכתי ומתפתח** לפרשנות אופי *סמלית* לפי השיטה
המערבית הטרופית:

- כ־48 כללי התחלה מבוססי מיקום שמש/ירח/מרקורי, היבטים ובתים נבחרים.
- כל מסקנה מקושרת למזהה כלל, נתון אסטרונומי ולמקור עריכתי, ומציגה
  גם השפעות בכיוונים מנוגדים.
- חלון "פרשנות אופי (ניסוי)" נפתח לאחר חישוב ומציג פרשנות,
  פירוט הכללים ומבנה נתונים להעברה עתידית למודל מקומי.
- חבילות כללים מדורגות בגרסאות JSON, עם אפשרות להוסיף/להחליף/לבטל
  כללים באמצעות Overlay מפורש שדורש התאמה לגרסת בסיס.
- ללא רשת או שירותי AI, וללא תוספת משמעותית לגודל ההתקנה.

זהו **אב־טיפוס של פרשנות אסטרולוגית סמלית, לא אבחון אופי מדעי**.
נוסחי הכללים הראשוניים טרם נבדקו מול מקורות אסטרולוגיים קנוניים
ספציפיים; יש לבקר את התוכן לפני הפצה מקצועית. עיון מלא:
`docs/interpretation-engine-v1.md`.

## גלגל מפה אינטראקטיבי (PR #8, טרם הופץ)

בחירה הדדית בין גלגל המפה לטבלת מיקומי הגופים, הדגשת היבטים,
ריחוף להצגת נתונים והעתקת תקציר מקומי. אין שינוי במיקום האסטרונומי
של הגופים: סמלים שהוזזו לקריאות מסומנים בקו אל המיקום המדויק.
